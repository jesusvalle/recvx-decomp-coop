# Cooperativo, hito 2d: inventario de P2, recoger objetos y baúl compartido — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Start en el mando 2 abre la pantalla de inventario de P2 (su bloque `itm[256..]`, su vida, su arma), manejada con el mando 2; P2 usa, combina, examina y equipa; recoge objetos con su botón de acción y usa el baúl general, compartido con P1.

**Architecture:** La pantalla original (`StatusMain`, tarea 9) se reutiliza con un "dueño". G13 (alrededor de `bhCheckSubTask`) inyecta el Start o la petición de P2 y, si la pantalla se abre, la marca como de P2. Mientras es de P2: `sys->pad_*` es el mando de P2 sin máscara (G2), `swork.pip` es su bloque (G14), `plp = &ply2` solo alrededor de `ItemTaskCheck`/`StatusMain` (G15), `sb_id`/`etc_idx`/`cb_flg 0x100` son los de su petición, y equipar marca el modo 3 como de P2 (`mn_mode3 = COOP_MN_P2`, cargador del 2c). La acción de P2 es un sondeo propio de las zonas de objeto y de baúl general (no llama a `bhCheckExmAtari`), con la misma prueba de posición y ángulo. G16 bloquea en la pantalla de P2 los objetos que van a un activador de suelo.

**Tech Stack:** C (MWCC, estilo C89), Python 3.13.

**Spec:** [docs/superpowers/specs/2026-10-11-coop-hito2d-design.md](../specs/2026-10-11-coop-hito2d-design.md)

## Review Focus

1. **El cierre de la pantalla de P2 restaura todo** (`swork.pip`, `plp`, `sb_id`, `etc_idx`, `cb_flg 0x100`, mando de P1): si no, P1 gastaría la munición de P2 o recogería con el índice de P2. Incluye el paso por el mapa, que no es un cierre. (Tarea 1: un único punto de cierre en `coopItemselectEnd`; revisión de código.)
2. **P1 y P2 piden pantalla a la vez** (Start o petición en el mismo frame): gana P1 y la de P2 espera; nunca se mezclan los bits de petición de los dos. (Tarea 1: `coopPreSubTask` no inyecta si P1 ya pidió; `coopPostSubTask` deshace la inyección si no se abrió.)
3. **P2 recoge con el inventario lleno, o la petición no puede abrirse** (P1 en una puerta, en un mensaje): P2 no se queda agachado para siempre. (Tarea 2: tiempo máximo de 300 frames y `bhStandPlayerMotion` sobre P2.)
4. **Equipar desde la pantalla de P2** (también al combinar, al coger un arma o al guardar el arma equipada en el baúl): carga el arma de P2 (modo 3 con `COOP_MN_P2`), nunca la de P1, y no cambia el crítico de P1 (`gm_flg 0x10000000`). Un `mn_mode0 = 3` de un guion (P1) no se marca como de P2. (Tarea 1: `coop_mn_pre` y `coop_gm_crit` en `coopItemselectBegin/End`.)
5. **El objeto cogido por P2 desaparece del mundo** (y no se duplica): `bhItmCk` (tarea 8) ve el `etc_idx` de la zona de P2 y `cb_flg 0x800` durante toda la pantalla. (Tarea 1: `etc_idx` de P2 desde la inyección hasta el cierre.)

```c
/* G13, antes de bhCheckSubTask: el Start o la petición de P2 se inyectan como si fueran de P1. */
void coopPreSubTask(void)
{
    coop_inj = 0;

    if ((coop_loaded == 0) || (coop_mounted == 0) || (coopDemo() != 0) || (coop_inv_owner != 0) || (coop_hidden != 0))
    {
        return;
    }

    if ((sys->ss_flg & 0x80000000) || (sys->st_flg & 0x1C040008) || (sys->cb_flg & 0x2064017) || (!(sys->ts_flg & 0x1000)))
    {
        return;
    }

    if ((ply2.stflg & 0x1000000) || (ply2.flg & 0x6) || (ply2.hp < 0))
    {
        return;
    }

    if (coop_p2_req != 0)
    {
        coop_p1_sb = sys->sb_id;
        coop_p1_etc = sys->etc_idx;
        coop_p1_cb100 = sys->cb_flg & 0x100;

        sys->sb_id = coop_req_sb;
        sys->etc_idx = coop_req_etc;
        sys->cb_flg |= 0x100 | coop_p2_req;

        coop_inj = 2;
    }
    else if ((coop_pad2raw.ps & 0x4000) && (!(coop_pad2raw.on & 0x80)) && (!(sys->pad_ps & 0x4000)))
    {
        coop_inj_ps = sys->pad_ps;
        coop_inj_on = sys->pad_on;

        sys->pad_ps |= 0x4000;
        sys->pad_on &= ~0x80;

        coop_inj = 1;
    }
}

/* G13, después de bhCheckSubTask: si se abrió el inventario, es de P2; si no, se deshace la inyección. */
void coopPostSubTask(void)
{
    if (coop_inj == 0)
    {
        return;
    }

    if (coop_inj == 1)
    {
        sys->pad_ps = coop_inj_ps;
        sys->pad_on = coop_inj_on;
    }

    if ((sys->st_flg & 0x8))
    {
        if (coop_inj == 1)
        {
            coop_p1_sb = sys->sb_id;
            coop_p1_etc = sys->etc_idx;
            coop_p1_cb100 = sys->cb_flg & 0x100;
        }

        coop_inv_owner = 2;
        coop_p2_req = 0;

        coopGetPad(&coop_pad1);
        coop_pad1.ps = 0;

        coopVibStop2();

        printf("[COOP] pantalla de P2 abierta\n");
    }
    else if (coop_inj == 2)
    {
        sys->cb_flg = (sys->cb_flg & ~(coop_p2_req | 0x100)) | coop_p1_cb100;
        sys->sb_id = coop_p1_sb;
        sys->etc_idx = coop_p1_etc;
    }

    coop_inj = 0;
}
```

```c
/* Acción de P2: como el tipo 4 de bhCheckExmAtari (objeto o baúl general), sin puertas, escaleras, examinar ni salientes (hito 4). */
static void coopActionP2(void)
{
    ATR_WORK* exp;
    O_WRK* op;
    float s;
    float c;
    float px;
    float pz;
    unsigned int bits;
    int ang;
    int n;
    int i;

    njSinCos(ply2.ay, &s, &c);

    px = ply2.px - (2.0f * s);
    pz = ply2.pz - (2.0f * c);

    n = rom->etc_n + sys->metc_n;

    for (i = 0; i < n; i++)
    {
        if (i < rom->etc_n)
        {
            exp = &rom->etcp[i];
        }
        else
        {
            exp = &sys->metcp[i - rom->etc_n];
        }

        if ((!(exp->flg & 0x1)) || (exp->type != 4) || (exp->flr_no != ply2.flr_no))
        {
            continue;
        }

        if ((exp->px > px) || ((exp->px + exp->w) < px) || (exp->pz > pz) || ((exp->pz + exp->d) < pz))
        {
            continue;
        }

        ang = ply2.ay + 8192;

        if ((((ang & 0xC000) == 0x8000) && ((exp->attr & 0x400))) || (((ang & 0xC000) == 0x4000) && ((exp->attr & 0x800))) || ((!(ang & 0xC000)) && ((exp->attr & 0x1000))) || (((ang & 0xC000) == 0xC000) && ((exp->attr & 0x2000))))
        {
            continue;
        }

        coop_req_etc = i;

        if (!(exp->attr & 0x2))
        {
            op = &sys->itwp[exp->prm0];

            if (!(op->flg & 0x1))
            {
                return;
            }

            coop_req_sb = op->id;

            bits = ((exp->attr & 0x10)) ? 0x20010 : 0x10;

            if ((exp->attr & 0x1))
            {
                /* Se agacha (bhCPM2_act_cro): la petición sale al terminar la animación. */
                ply2.flg |= 0x10000;
                ply2.stflg |= 0x10000;

                ply2.mode0 = 1;
                ply2.mode1 = 0;
                ply2.mode2 = 19;
                ply2.mode3 = 0;

                coop_pend = bits;
            }
            else
            {
                coop_p2_req = bits;
            }

            return;
        }

        /* Baúles especiales A y B: solo P1. */
        if ((exp->attr & 0xC))
        {
            return;
        }

        coop_req_sb = sys->sb_id;

        if (exp->prm0 == 0xFF)
        {
            coop_p2_req = 0x40000;
        }
        else
        {
            op = &sys->obwp[exp->prm0];

            if ((op->flg & 0x1))
            {
                op->type = 100;

                *(int*)&op->mode0 = 0;

                ply2.flg |= 0x10000;
                ply2.stflg |= 0x18000;

                ply2.mode0 = 1;
                ply2.mode1 = 0;
                ply2.mode2 = 0;
                ply2.mode3 = 0;

                coop_lid = exp->prm0;
            }
        }

        return;
    }
}

/* Dentro de la ventana de P2, tras bhControlPlayer: termina las peticiones en curso o lanza una nueva. */
static void coopRequestP2(void)
{
    if (coop_pend != 0)
    {
        if ((ply2.mode0 != 1) || (ply2.mode1 != 0) || (ply2.mode2 != 19))
        {
            coop_pend = 0;
        }
        else if ((sys->cb_flg & 0x10) && (!(coop_save.cb_flg & 0x10)))
        {
            coop_p2_req = coop_pend;
            coop_pend = 0;
        }
    }

    if (coop_p2_req != 0)
    {
        /* Si no se puede abrir (P1 en una puerta, mensajes...), P2 no se queda agachado para siempre. */
        if (++coop_req_ct > 300)
        {
            printf("[COOP] petición de P2 caducada\n");

            coop_p2_req = 0;
            coop_req_ct = 0;

            bhStandPlayerMotion();
        }

        return;
    }

    coop_req_ct = 0;

    if ((coop_pend != 0) || (coop_lid >= 0))
    {
        return;
    }

    if ((ply2.mode0 == 1) && (!(ply2.stflg & 0x10080)) && (!(ply2.flg & 0x4000004)) && (!(sys->cb_flg & 0x4017)) && (!(coop_save.cb_flg & 0x64010)) && (!(ply.stflg & 0x10000)) && (coop_pad2raw.ps & 0x200))
    {
        coopActionP2();
    }
}
```
