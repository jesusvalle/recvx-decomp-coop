# Cooperativo, hito 2a: P2 con Claire B, manos y coleta — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** P2 lleva el traje alternativo de Claire (`SYSTEM.AFS[14]`), las manos con el arma de P1 y su propia coleta, sin tocar los datos de P1.

**Architecture:** Un gancho nuevo en el paso 10 del modo 1 del cargador (G8) lee el fichero de Claire B y una copia reducida de `bhReadPlayerData` lo vuelca en memoria de P2 (pool de 64 KB del hito 1 + texturas). G4 pasa de `bhReadPlayerData` a `bhReadWeaponData` y clona los objetos de arma de P1 para P2. La coleta y las manos son `O_WRK` estáticos de `coop.c`, actualizados dentro de `coopBegin`/`coopEnd` y dibujados después del cuerpo de P2.

**Tech Stack:** C (MWCC para PS2, estilo C89: variables al principio de la función), Python 3.13 (`.venv`) para las herramientas, PowerShell para el arnés de PCSX2 2.4.

**Spec:** [docs/superpowers/specs/2026-10-10-coop-hito2a-design.md](../specs/2026-10-10-coop-hito2a-design.md)

## Global Constraints

- Todo el código nuevo va dentro de `#ifdef COOP`. Sin `COOP`, los segmentos `PT_LOAD` del ELF deben salir idénticos a `.superpowers/sdd/2026-10-09-coop-hito1/tools/baseline_main.elf`.
- No se cambia la estructura de `SYS_WORK` ni de `BH_PWORK`.
- Estilo del archivo que se toca: llaves Allman, variables declaradas al principio de la función, flags en hex, sin `// 100% matching!` en código nuevo.
- **Sin commits ni PR** (preferencia permanente del usuario): cada tarea termina dejando los cambios en el working tree.
- Build: `.venv/Scripts/python.exe compile.py` (sin `--sdk303`). La ISO se genera con `.venv/Scripts/python.exe mkiso.py -m insert` **con PCSX2 cerrado**, y se comprueba que la fecha de `iso/RECVX_NEW.iso` es posterior a la de `elf/main.elf`.
- Los `printf` del juego no se ven en PCSX2. La verificación en tiempo de ejecución es con capturas (`Snap`) y con `ramread.py` (Tarea 1).
- Nunca pulsar Alt en PCSX2. Si el usuario está jugando, no enviar teclas.
- Al terminar las pruebas, `Restore-Config` (con PCSX2 cerrado) y comprobar que `PCSX2.ini` queda igual que la copia de seguridad.
- `P2_FILE`: `14` si `sys->costume == 0`; si no, `10`.

## Review Focus

1. **P1 cambia de arma desde el inventario con P2 en pantalla:** las manos de P2 cambian a la nueva arma y P2 no se mueve. No debe quedar ningún frame con un clon que apunte a datos de arma ya sobrescritos. (Tarea 3, paso de prueba del cambio de arma.)
2. **La coleta de P1 sigue igual con P2 presente:** si `coop_hair` llegara a `bhObjClpn` sin `flg 0x100000`, usaría el buffer `sys->pletcp` de P1 y le rompería la coleta. (Tarea 4: revisión de código y captura comparando las dos coletas.)
3. **Reintentar tras morir o cargar partida:** pasan otra vez por el modo 1. P2 debe volver con su traje, sin texturas duplicadas que agoten el pool: el contador de referencias no debe hacer crecer `Ps2_free_texmemsize` hacia abajo en cada reintento. (Tarea 5: dos lecturas de `ramread.py` separadas por un reintento o una vuelta al título; la memoria de texturas libre debe ser la misma.)
4. **Salas con mucha textura:** el pool de texturas no debe llegar al `exit(0)`. (Tarea 5: cálculo del peor caso con la base medida.)
5. **Demo del título y P1 que no es Claire:** P2 no se carga en el demo, y se oculta con `sys->ply_id != 0`. (Tarea 2: revisión de código de `coopLoadPlayer2` y `coopHideCondition`; Tarea 5: demo en PCSX2.)

```python
"""Lee la RAM del EE de un savestate de PCSX2 sin comprimir e imprime el estado de memoria y de P2.

uso: ramread.py [--state RUTA.p2s]   (por defecto, el .p2s más reciente de Documents/PCSX2/sstates)
"""
import argparse, glob, os, pathlib, re, struct, sys, zipfile

root = pathlib.Path(__file__).resolve().parents[4]
ap = argparse.ArgumentParser()
ap.add_argument("--state")
a = ap.parse_args()
state = a.state or max(glob.glob(os.path.expandvars(r"$USERPROFILE/Documents/PCSX2/sstates/*.p2s")), key=os.path.getmtime)
z = zipfile.ZipFile(state)
info = z.getinfo("eeMemory.bin")
if info.compress_type not in (0, 8):
    sys.exit(f"{state}: eeMemory.bin comprimido con el método {info.compress_type}; usa Set-TestConfig (SavestateCompressionType = 0)")
ram = z.read("eeMemory.bin")

syms = {}
for line in (root / "elf/main.elf.xMAP").read_text(encoding="latin-1").splitlines():
    m = re.match(r"\s+([0-9A-Fa-f]{8})\s+[0-9A-Fa-f]{8}\s+\.\S+\s+(\S+)\s", line)
    if m:
        syms.setdefault(m.group(2), int(m.group(1), 16))

def u32(addr): return struct.unpack_from("<I", ram, addr & 0x1FFFFFF)[0]
def s32(addr): return struct.unpack_from("<i", ram, addr & 0x1FFFFFF)[0]
def u8(addr): return ram[addr & 0x1FFFFFF]

print("savestate =", state)
sysp = u32(syms["sys"])
SYS = {"memp": 0x1B17C, "mempb": 0x1B180, "endp": 0x1B184, "lmmdlp": 0x1B190}
v = {k: u32(sysp + o) for k, o in SYS.items()}
for k, x in v.items():
    print(f"sys->{k} = {x:#010x}")
print("sys->ply_id =", u8(sysp + 0x84), " sys->costume =", s32(sysp + 0x28A70))
print(f"libre en el pool (endp - memp) = {v['endp'] - v['memp']} B")
print(f"bajo mempb (mempb - lmmdlp) = {v['mempb'] - v['lmmdlp']} B")
print("Ps2_free_texmemsize =", u32(syms["Ps2_free_texmemsize"]))
for name in ("coop_enabled", "coop_loaded", "coop_mdl_n", "coop_ld_mode", "coop_wpnr_no", "coop_hidden"):
    print(name, "=", s32(syms[name]) if name in syms else "(no está en el xMAP)")
```

```c
/* Copia reducida de bhReadPlayerData (dread.c): solo modelos, skin, owP y texturas, en memoria de P2. */
static int coopReadPlayer2Data(unsigned char* datp)
{
    ML_WORK* mdlp;
    unsigned char* mp;
    unsigned char* tp;
    unsigned int dt0;
    unsigned int dt1;
    unsigned int need;
    int temp;
    int size;
    int i;

    coop_loaded = 0;
    coop_mdl_n = 0;

    npSetMemory((unsigned char*)coop_mdl, sizeof(coop_mdl), 0);

    for (i = 0; i < 16; i++)
    {
        coop_skp[i] = NULL;
        coop_mbp[i] = NULL;
        coop_txp[i] = NULL;
    }

    dt0 = *(unsigned int*)datp;
    datp += 4;

    if ((dt0 + 256) > COOP_MODEL_POOL_SIZE)
    {
        printf("[COOP] el modelo de P2 no cabe (%d)\n", dt0);
        return 0;
    }

    njMemCopy(coop_pool, datp, dt0);

    mp = coop_pool;
    mdlp = coop_mdl;

    while ((dt1 = *(unsigned int*)mp) != -1)
    {
        if (dt1 != 0)
        {
            mp += 4;

            if (*(unsigned int*)mp == SKIN_MAGIC)
            {
                coop_skp[coop_mdl_n] = (int*)&mp[4];
            }
            else if (coop_mdl_n < 16)
            {
                bhMlbBinRealize(mp, mdlp);

                if (coop_skp[coop_mdl_n] != NULL)
                {
                    npSkinConvert(mdlp->objP, coop_skp[coop_mdl_n]);
                }

                coop_mbp[coop_mdl_n] = mdlp->objP;
                coop_txp[coop_mdl_n] = mdlp->texP;

                mdlp++;
                coop_mdl_n++;
            }

            mp = &mp[dt1];
        }
        else
        {
            mp += 4;
        }
    }

    datp = &datp[dt0];

    dt1 = *(unsigned int*)datp;
    datp = &datp[4 + dt1];

    dt1 = *(unsigned int*)datp;
    datp = &datp[4 + dt1];

    mp = (unsigned char*)(((int)&coop_pool[dt0] + 256) & ~0xFF);

    for (i = 0; i < coop_mdl_n; i++)
    {
        size = coop_mdl[i].obj_num * sizeof(O_WORK);

        if ((mp + size) > &coop_pool[COOP_MODEL_POOL_SIZE])
        {
            printf("[COOP] los owP de P2 no caben\n");

            coop_mdl_n = 0;
            return 0;
        }

        coop_mdl[i].owP = (O_WORK*)mp;

        npSetMemory(mp, size, 0);

        mp = (unsigned char*)ALIGN_UP((int)&mp[size], 32);
    }

    need = 0;
    tp = datp;

    for (i = 0; i < coop_mdl_n; i++)
    {
        if (coop_mdl[i].texP != NULL)
        {
            temp = *(unsigned int*)tp;

            if ((temp & 0x80000000))
            {
                tp += 4;
                tp = (unsigned char*)(((int)tp + 31) & ~0x1F);
                temp &= ~0x80000000;
            }
            else
            {
                tp += 4;
            }

            need += temp;
            tp = &tp[temp];
        }
    }

    if (Ps2_free_texmemsize < need)
    {
        printf("[COOP] sin memoria de texturas para P2 (%d < %d)\n", Ps2_free_texmemsize, need);

        coop_mdl_n = 0;
        return 0;
    }

    for (i = 0; i < coop_mdl_n; i++)
    {
        if (coop_mdl[i].texP != NULL)
        {
            temp = *(unsigned int*)datp;

            if ((temp & 0x80000000))
            {
                datp += 4;
                datp = (unsigned char*)(((int)datp + 31) & ~0x1F);
                temp &= ~0x80000000;
            }
            else
            {
                datp += 4;
            }

            coop_mdl[i].flg |= 0x200;

            bhSetMemPvpTexture(coop_mdl[i].texP, datp, 0);

            datp = &datp[temp];
        }
        else
        {
            coop_mdl[i].flg &= ~0x200;
        }
    }

    coop_loaded = 1;

    printf("[COOP] P2 cargado: fichero %d, %d modelos, %d B de modelo\n", coop_ld_file, coop_mdl_n, dt0);
    return 1;
}
```

void coopCloneWeapon(void)
{
    int k;
    int i;
    int n;
    int used;
    O_WRK* src;
    O_WRK* dst;
    NJS_CNK_OBJECT* so;
    NJS_CNK_OBJECT* dobj;
    O_WORK* ow;

    coop_wpn_ok[0] = 0;
    coop_wpn_ok[1] = 0;

    if (coop_enabled == 0)
    {
        return;
    }

    used = 0;

    for (k = 0; k < 2; k++)
    {
        src = &sys->obwp[k];
        dst = &coop_wpn[k];

        if ((!(src->flg & 0x1)) || (src->mlwP == NULL) || (src->mlwP->objP == NULL) || (src->mlwP->owP == NULL))
        {
            continue;
        }

        n = src->mlwP->obj_num;

        if ((used + ALIGN_UP(n * (int)sizeof(NJS_CNK_OBJECT), 64) + ALIGN_UP(n * (int)sizeof(O_WORK), 64)) > coop_wpn_area_size)
        {
            printf("[COOP] las manos de P2 no caben\n");
            continue;
        }

        npCopyMemory((unsigned char*)dst, (unsigned char*)src, sizeof(O_WRK));

        dst->mlwP = &dst->mdl[src->mlwP - src->mdl];
        dst->mtx = (void*)dst->mtxbuf;

        so = src->mlwP->objP;
        dobj = (NJS_CNK_OBJECT*)&coop_wpn_area[used];

        npCopyMemory((unsigned char*)dobj, (unsigned char*)so, n * sizeof(NJS_CNK_OBJECT));

        for (i = 0; i < n; i++)
        {
            if ((dobj[i].child != NULL) && (dobj[i].child >= so) && (dobj[i].child < &so[n]))
            {
                dobj[i].child = &dobj[dobj[i].child - so];
            }

            if ((dobj[i].sibling != NULL) && (dobj[i].sibling >= so) && (dobj[i].sibling < &so[n]))
            {
                dobj[i].sibling = &dobj[dobj[i].sibling - so];
            }
        }

        used += ALIGN_UP(n * (int)sizeof(NJS_CNK_OBJECT), 64);

        ow = (O_WORK*)&coop_wpn_area[used];

        npCopyMemory((unsigned char*)ow, (unsigned char*)src->mlwP->owP, n * sizeof(O_WORK));

        used += ALIGN_UP(n * (int)sizeof(O_WORK), 64);

        dst->mlwP->objP = dobj;
        dst->mlwP->owP = ow;
        dst->lkwkp = (unsigned char*)&ply2;

        coop_wpn_ok[k] = 1;

    /* El mechero (1) es de P1: P2 lo lleva en la mano, pero sin su luz. */
    coop_wpnr_no = (ply.wpnr_no == 1) ? 0 : ply.wpnr_no;

}
