# Cooperativo, hito 8: P2 en escaleras y eventos — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** P2 sube y baja escaleras, escalerillas, escalones y salientes de la sala con su botón de acción, y sus activadores de suelo disparan los eventos de la sala; si el evento toma el control, P1 y P2 se cambian de sitio.

**Architecture:** G33 filtra `bhCheckExmAtari` para que con `plp == &ply2` solo vea zonas de tipo 1 y 2; `coopRequestP2` lo llama antes de `coopActionP2`. P2 tiene su propio `pl_htp` (`coop_pl_htp2`), que viaja con `coopBegin`/`coopEnd`. El activador de suelo de P2 se pasa al `cb_flg` de P1 tras `coopEnd` cuando P1 no tiene uno; G34, alrededor de `bhControlEvent`, intercambia las posiciones antes del guion y lo deshace si el guion no toma el control.

**Tech Stack:** C (MWCC, estilo C89), Python 3.13 (herramientas de prueba).

**Spec:** [docs/superpowers/specs/2026-10-10-coop-hito8-design.md](../specs/2026-10-10-coop-hito8-design.md)

## Global Constraints

- Todo el código nuevo dentro de `#ifdef COOP`; sin `COOP`, `PT_LOAD` idéntico a `baseline_main.elf`.
- No se cambia la estructura de `SYS_WORK` ni de `BH_PWORK`. El estado nuevo, en `static` de coop.c.
- Estilo del archivo: Allman, variables al principio, flags en hex. Comentarios en español.
- Sin commits ni PR (regla del usuario: solo el commit que pida).
- Alcance: escaleras y eventos. P2 sigue sin abrir puertas, examinar ni usar objetos clave (hito 4).
- `COOP_TEST` nunca queda activo en el build final.

## Review Focus

1. **Escalera bloqueada para siempre:** si P2 deja una escalera a medias (evento, puerta, recolocación), la marca `attr 0x400000` tiene que quitarse; si no, P1 no podrá usarla nunca. (Tarea 1: `coopLeaveStairsP2` al principio de `coopPlaceNearP1`.)
2. **`pl_htp` de P1 pisado:** P2 en una escalera no debe cambiar la escalera que lee P1 (y al revés). (Tarea 1: `coopBegin`/`coopEnd`.)
3. **Teletransporte sin cinemática:** pisar con P2 una zona que no toma el control no mueve a nadie. (Tarea 2: `coopEventPost` deshace el intercambio.)
4. **Intercambio en mal momento:** nunca con alguno en una escalera, oculto, muerto, agarrado o en una puerta. (Tarea 2: `coopCanSwap`.)
5. **P2 abre puertas o examina:** el filtro G33 solo deja tipos 1 y 2 para P2. (Tarea 1.)

```c
/* El activador de suelo de P2 lo ve el guion si P1 no pisa ninguno (gana P1). Las zonas de frente (tipo 0 con attr 1) son de objetos clave: hito 4. */
static void coopTriggerP2(unsigned int trg, unsigned int idx)
{
    ATR_WORK* fp;

    if ((sys->cb_flg & 0x8000200))
    {
        coop_swap_wait = 0;
        return;
    }

    if (trg == 0)
    {
        return;
    }

    if ((int)idx < rom->flr_n)
    {
        fp = &rom->flrp[idx];
    }
    else
    {
        fp = &sys->mflrp[idx - rom->flr_n];
    }

    if ((fp->type == 0) && ((fp->attr & 0x1)))
    {
        return;
    }

    sys->cb_flg |= trg;
    sys->flr_idx = idx;

    coop_trg_p2 = 1;
}
```

- [ ] **Step 4: intercambio.**

```c
/* P1 y P2 se cambian de sitio (posición, ángulo y piso). Fuera de coopBegin/coopEnd. */
static void coopSwapPos(void)
{
    NJS_POINT3 p1;
    NJS_POINT3 p2;
    int ay1;
    int ay2;
    int fl1;
    int fl2;

    p1.x = ply.px;
    p1.y = ply.py;
    p1.z = ply.pz;
    p2.x = ply2.px;
    p2.y = ply2.py;
    p2.z = ply2.pz;

    ay1 = ply.ay;
    ay2 = ply2.ay;
    fl1 = ply.flr_no;
    fl2 = ply2.flr_no;

    coopSetPos(&ply, &p2);
    coopSetPos(&ply2, &p1);

    ply.ay = ply.ayb = ay2;
    ply2.ay = ply2.ayb = ay1;
    ply.flr_no = fl2;
    ply2.flr_no = fl1;

    bhCalcModel(&ply);
    bhCalcModel(&ply2);
}

static int coopCanSwap(void)
{
    if ((coop_loaded == 0) || (coopDemo() != 0) || (coop_hidden != 0) || (coopP2Dead() != 0) || (coopP2Held() != 0))
    {
        return 0;
    }

    if ((ply.mode0 != 1) || (ply2.mode0 != 1) || ((ply.stflg | ply2.stflg) & 0x1000030) || ((sys->cb_flg & 0x5)))
    {
        return 0;
    }

    return 1;
}

/* El guion ha tomado el control: cinemática, jugador por guion u oculto. */
static int coopTakeover(void)
{
    if (((sys->cb_flg & 0x4)) && (!(coop_ev_cb & 0x4)))
    {
        return 1;
    }

    if ((ply.mode0 == 7) && (coop_ev_md != 7))
    {
        return 1;
    }

    if (((ply.stflg & 0x1000000)) && (!(coop_ev_stflg & 0x1000000)))
    {
        return 1;
    }

    return 0;
}

/* G34 (bhSysCallEvent): antes de bhControlEvent. */
void coopEventPre(void)
{
    int i;

    coop_ev_cb = sys->cb_flg;
    coop_ev_md = ply.mode0;
    coop_ev_stflg = ply.stflg;

    for (i = 0; i < 16; i++)
    {
        coop_ev_st[i] = (bhEtask[i].status != 0) ? 1 : 0;
    }

    coop_can = coopCanSwap();

    coop_swapped = 0;

    if ((coop_trg_p2 != 0) && (coop_can != 0))
    {
        coopSwapPos();

        coop_swapped = 1;
    }
}

/* G34: después de bhControlEvent. Sin toma de control se deshace; una tarea nueva deja 30 frames de margen. */
void coopEventPost(void)
{
    int i;
    int fresh;

    fresh = 0;

    for (i = 0; i < 16; i++)
    {
        if ((coop_ev_st[i] == 0) && (bhEtask[i].status != 0))
        {
            fresh = 1;
        }
    }

    if (coop_swapped != 0)
    {
        if (coopTakeover() == 0)
        {
            coopSwapPos();

            coop_swap_wait = (fresh != 0) ? 30 : 0;
        }
        else
        {
            printf("[COOP] evento de P2: P1 y P2 intercambiados\n");

            coop_swap_wait = 0;
        }
    }
    else if (coop_swap_wait > 0)
    {
        if (coopTakeover() != 0)
        {
            if (coop_can != 0)
            {
                coopSwapPos();

                printf("[COOP] evento de P2 (retrasado): P1 y P2 intercambiados\n");
            }

            coop_swap_wait = 0;
        }
        else if (((sys->cb_flg & 0x1)))
        {
            coop_swap_wait = 0;
        }
        else
        {
            coop_swap_wait--;
        }
    }

    coop_trg_p2 = 0;
}
```
